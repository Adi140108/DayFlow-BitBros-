# Dayflow — Human Resource Management System

> **Every workday, perfectly aligned.**

Dayflow is a **Human Resource Management System (HRMS)** designed to digitize and streamline essential HR operations such as employee management, attendance tracking, leave management, payroll visibility, and approval workflows.

## 🚧 Project Status

**Temporary / Under Development**

This repository is currently being used for development and experimentation. Features and implementation details may change as development progresses.

## 🎯 Features

### 🔐 Authentication & Authorization

* Employee and HR/Admin registration
* Secure sign-in
* Email verification
* Role-based access control
* Separate access for Employees and HR/Admin

### 👤 Employee Management

* Employee profiles
* Personal details
* Job details
* Salary structure
* Documents
* Profile picture
* Limited profile editing for employees
* Full employee management for HR/Admin

### 📊 Attendance Management

* Daily attendance tracking
* Weekly attendance view
* Employee check-in/check-out
* Attendance statuses:

  * Present
  * Absent
  * Half-day
  * Leave
* Employees can view their own attendance
* HR/Admin can view attendance for all employees

### 🏖️ Leave & Time-Off Management

* Apply for leave
* Leave types:

  * Paid
  * Sick
  * Unpaid
* Select date ranges
* Add remarks
* Leave status tracking:

  * Pending
  * Approved
  * Rejected
* HR/Admin approval and rejection
* Approval comments

### 💰 Payroll / Salary Management

* Employees can view their salary information
* Employee payroll information is read-only
* HR/Admin can view payroll for all employees
* HR/Admin can update salary structures
* Payroll accuracy management

### 📈 Dashboards

#### Employee Dashboard

* Profile
* Attendance
* Leave Requests
* Logout
* Recent activity and alerts

#### HR/Admin Dashboard

* Employee list
* Attendance records
* Leave approvals
* Employee switching and management

## 👥 User Roles

| Role         | Access                                                    |
| ------------ | --------------------------------------------------------- |
| **Employee** | Profile, attendance, leave requests, salary details       |
| **HR/Admin** | Employee management, attendance, leave approvals, payroll |
