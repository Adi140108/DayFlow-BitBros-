# Dayflow Responsive Guidelines

## Layout Breakpoints
- **Mobile**: `< 768px` (Uses Scaffold Drawer & Bottom Navigation Bar)
- **Tablet**: `768px - 1023px` (Uses Collapsed Sidebar & TopBar)
- **Desktop**: `>= 1024px` (Uses Full Expanded Sidebar & TopBar, max content width 1400px)

## Dense Data Strategy
- On Desktop/Tablet: Use `AppTable` with explicit column widths and flex expansion.
- On Mobile: Use stacked list cards or horizontally scrollable data surfaces to avoid cramped touch targets.
